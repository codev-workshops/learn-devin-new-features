# Planted defects in `apps/web`

These are **features of the course** (see root `AGENTS.md` §1). Do not fix them on `main`; remediation demos run on throwaway branches that are closed without merging. Both plants live in the merchandiser console only — the storefronts are meant to pass an accessibility scan.

| ID      | Where                                                                                                    | What                                                                                                                                                                                           | WCAG                          | Expected finding                                                |
| ------- | -------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------- | --------------------------------------------------------------- |
| a11y-01 | `/admin` → Inventory → "Adjust" column (`src/admin/InventoryPage.tsx`)                                   | Two icon-only `<button>`s (− / +) whose SVG is `aria-hidden` and which carry no `aria-label`, `title` or visible text, so they have an empty accessible name.                                  | 4.1.2 Name, Role, Value (A)   | axe `button-name`; screen readers announce "button, button".    |
| a11y-02 | `/admin/price-lists` → Price column (`src/admin/PriceListsPage.tsx`, `.price-badge` in `src/styles.css`) | Price badge rendered as `#8f9bb3` text on `#ffffff` at normal weight/size: contrast ratio ≈ 3.1:1, below the 4.5:1 minimum for body text (it would only pass for large text or UI components). | 1.4.3 Contrast (Minimum) (AA) | axe `color-contrast`; Lighthouse accessibility flags the badge. |

How to see them: start the app in mock mode (`pnpm --filter @harbourline/web run dev`), open `/admin`, sign in with the pre-filled merchandiser, then run axe DevTools or Lighthouse on Inventory and Price lists. `src/admin/admin.test.tsx` deliberately asserts that the icon buttons have no `aria-label`, so a remediation branch is expected to update that test too.

Not planted here but visible through the storefront (they come from `packages/contracts/seed-spec.yaml#planted_edge_cases`): Lamp Week prices rounded half-up, three low-stock lamps, Trailhead pre-order SKUs with zero on-hand, and six abandoned carts stuck with a pending payment.
