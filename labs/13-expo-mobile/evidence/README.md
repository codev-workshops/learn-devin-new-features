This is the evidence from the run that built the lab. It is the fixture fallback for criteria 1–3 (Android) and 6–8 (iOS) when you cannot boot an emulator or a macOS machine. Your own run goes in `labs/13-expo-mobile/MOBILE-REPORT.md` (not committed).
