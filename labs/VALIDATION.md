# Lab validation — blind facilitator pilot (W5-15)

Pilot run 22 Oct 2026 by the W5-15 child session (a Devin agent, not a human cohort) on a freshly cloned VM snapshot of `main`. For every lab the generated page (`labs/<nn>-*/index.html`, built by `pnpm labs:build`) was read top to bottom **without opening the answer** (`answer.md` and the `<template>` were not read), `pnpm lab:reset -- <nn>` was run, and the default zero-credential fixture path from the credential matrix was attempted. Live integrations were not exercised (no credentials, by policy); each lab's own not-exercised list stands.

How to read the columns:

- **Budget** — `duration_minutes` from `lab.json`; the human timing the learner is promised.
- **Pilot** — agent wall-clock for the fixture commands only (reading time not measured). A human time trial remains a facilitator follow-up.
- **Ambiguity** — what a first-time learner could reasonably misread.
- **Prompt hints** — learner-facing text that tells the learner what to type to Devin. A fenced `prompt` block is a build failure (`labs/build.mjs`); this column catches the softer kind.
