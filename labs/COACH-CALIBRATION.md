# Coach calibration (cross-lab)

Plan §5 / W5-coach. One deliberately generic mediocre transcript —
[`coach-dryrun/fixtures/generic-mediocre.md`](coach-dryrun/fixtures/generic-mediocre.md), which names
**no lab-specific point** — is graded by all fifteen per-lab coaches in dry-run mode
(`[mm:ss]` markers, `graded_by: inline`, no push). Each coach's report is in
[`coach-dryrun/reports/`](coach-dryrun/reports/). The coaches agree with each other when the same
content-free answer lands in a narrow band: the spread across all labs must be **≤ 15 points**.

```
node labs/coach-dryrun/calibrate.mjs            # check reports + this table (also runs in pnpm test)
node labs/coach-dryrun/calibrate.mjs --write    # regenerate the table below after re-grading
```

How the generic segments map onto each lab: `framing` → framing; the first and second segments between
framing and the closing update → `checkpoint-a`, `checkpoint-b` (lab 12's `update-15` takes slot a);
`update` → update; `objection-n` → objection-n (labs with two objections ignore `objection-3`).
`calibrate.mjs` asserts the reported timings agree with those markers, every must-mention point is
graded *not mentioned*, the must-mention ids and weights match the lab's own dry run, the planted
fillers and pause are reported, and totals equal the sum of the five components.

## Reading the result

- **Spread is within band, so no per-lab skill was changed.** No lab is an outlier; the rule
  (adjust only the outlying lab's own anchors or weights, never `articulation-base`) was not triggered.
- Accuracy is 4/30 everywhere: the transcript names no point and contradicts nothing. The spread comes
  from structure (11–13), relevance (7–10) and recovery (3–4, the two three-objection labs concede
  one). Lab 12 is lowest (32) because its incident-commander anchors require the update skeleton and a
  number up front; labs 02/03 are highest (37) because "impact mentioned once, hedged" is their
  10–13 anchor.
- Every generic total sits far below the lab's own mediocre dry run (55–64), confirming the
  lab-specific must-mention points carry the difference. It sits close to, and for lab 12 just below,
  the lab's off-track run: a content-free answer and a wrong one score alike. That is intended —
  off-track transcripts name one or two points.
